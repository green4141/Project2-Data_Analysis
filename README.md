# 🚀 **Project2 - Data Analysis**  
### 다양한 데이터셋 기반의 머신러닝 모델 성능 비교 분석

> **2025 더조은 아카데미 2차 프로젝트**

---

## 📊 분석 개요

본 프로젝트는 다양한 **머신러닝 모델**을 적용하여 **성능 비교 분석**을 진행합니다. 데이터 크기, 변수 수, 변수 유형 등 데이터의 특성에 따라 최적의 모델이 달라지므로, **분류(Classification)** 와 **회귀(Regression)** 문제 유형별로 가장 적합한 모델을 실증적으로 검증합니다. 이 분석을 통해, 경험적 추정이 아닌 **구조적 특성 기반의 모델 선택 기준**을 도출하는 것을 목표로 합니다.
